- **Concepts Used:**
  - Functions, Switch Case, Loops, Conditional Statements, Input Validation.  
- **Features:**
  - Supports multiple conversions in one run.  
  - Error handling for invalid inputs.

⚙️ How to Run:

Clone the repository or copy the .cpp file.
Compile using any C++ compiler: g++ currency_converter.cpp -o converter
Run the program: ./converter
Follow on-screen instructions to select a currency and enter an amount.
